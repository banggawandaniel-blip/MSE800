College Management System 

This project presents a simple College Management System focusing on three main areas: Students, Lecturers, and Courses.
The Use Case Diagram shows how the users interact with the system. Students can enrol in courses and view their enrolled courses. Lecturers can view their assigned courses and the students enrolled in their courses.
The Activity Diagram illustrates the student course enrolment process. The student views the available courses, selects a course, and the system checks whether the course is available. If the course is available, the student is enrolled and receives confirmation. If the course is not available, the system displays an appropriate message.
The Class Diagram represents the main classes in the system: Student, Lecturer, and Course. Students can enrol in courses, while lecturers teach courses. The diagrams were designed to be simple and beginner-friendly while demonstrating the basic concepts of UML and system design.
