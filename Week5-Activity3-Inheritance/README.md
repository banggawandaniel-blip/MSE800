# University OOP Project

## Description

This project demonstrates Object-Oriented Programming (OOP) concepts using Python.

The program is based on a university class hierarchy and uses inheritance between Person, Student, Staff, General, and Academic classes.

## Features

- Calculates and displays the number of publications for a lecturer.
- Calculates and displays the hourly pay rate for a general staff member.
- Demonstrates classes and objects.
- Demonstrates attributes and methods.
- Demonstrates inheritance.

## Class Hierarchy

Person
├── Student
└── Staff
    ├── General
    └── Academic

## How to Run

Run the following command in the terminal:

python university.py
